Library startup and recovery

This is a general operating card. Follow the runbook for your installation before changing services or restoring data.

  1. Connect the server to its verified power supply and local network, then start it.
  2. Open the Cyberdeck Hub address provided by the administrator. Browse ZIM libraries from the Hub navigation.
  3. If the library does not open, check the server address and follow the certificate help page linked from the Hub.
  4. For service status, backups, or recovery, use the runbook for this installation. Do not assume a successful checksum proves that search, client access, or offline use works.
  5. Use the documented shutdown procedure and wait for the server to stop before disconnecting power.
